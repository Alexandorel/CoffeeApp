
## Ghid rulare aplicatie
1.Descarcare import sql "cafenea2_0.sql".

1.Populare baza de date
```bash
  Accesare : http://localhost/phpmyadmin/index.php
  
  -> import -> Choose File -> "cafenea2_0.sql" 
```

1.Pornirea serverelor din xxamp:

```bash
  MySQL Database

  Apache Web Server
```

2.Accesati directorul proiectului

3.Initializare backend

```bash
  ->terminal ->cd backend -> node server.js
```

4.Initializare frontend
```bash
  ->terminal ->cd frontend -> npm start
```
